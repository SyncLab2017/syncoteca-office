## НДС

- НДС внутренний рынок (Россия): **22%** (актуально с 2026)
- НДС международные сделки (экспорт): **0%**
- НДС начисляется **сверху** (не включён в цену по умолчанию)

### Если задана сумма БЕЗ НДС:
- С НДС = Сумма × 1,22
- НДС = Сумма × 0,22

### Если задана сумма С НДС:
- Без НДС = Сумма / 1,22
- НДС = Сумма − Без НДС

### Международная сделка (нерезидент):
- НДС 22% удерживается в РФ = Сумма / 1,22
- Налог на доход нерезидента 10% = (Сумма − НДС) × 0,10
- Поступление на счёт = Сумма − НДС − Налог на доход

## Авторские выплаты — типы контрагентов

### А) Физлицо (без ИП) — НДФЛ 13%
SYNC LAB = налоговый агент: выплачивает нетто, удерживает НДФЛ.

Если задана сумма **«на руки»**:
- Gross = Сумма_на_руки / 0,87
- НДФЛ = Gross × 0,13
- В расчёт маржи идёт **Gross**
- НДС к зачёту = 0 (НДФЛ ≠ НДС)

### Б) Юрлицо / ИП с НДС
Ставки НДС: **22%** (ПМИ, НМИ, С.Б.А., крупные паблишеры), **7%** (юристы), **5%** (отдельные ИП). Ставку уточнять по договору.

- Авт. с НДС = Авт. без НДС × (1 + ставка)
- НДС → к зачёту (уменьшает НДС к уплате)

### В) ИП без НДС (УСН / ПСН / НПД)
- Платим сумму по договору. НДС к зачёту = 0.

### Г) ИП с налогом на УСН (смешанный)
Если задана сумма **«на руки»** + указан % УСН + % НДС:

⚠️ НДС начисляется **сверху** от Base — НЕ включается в Base, НЕ считается методом «в том числе».

- Base = Сумма_на_руки / (1 − УСН%)  ← gross с учётом налога УСН
- НДС = Base × НДС%  ← НДС сверху от Base
- Платим контрагенту: Base + НДС
- НДС к зачёту = 0

**Проверка (контроль):** Base − Base × УСН% = Сумма_на_руки ✓

**Примеры:**
- На руки 100 руб + УСН 6% + НДС 5%:
  Base = 100 / 0,94 = 106,38; НДС = 106,38 × 0,05 = 5,32; Платим **111,70**
  Проверка: 106,38 − 6,38 = 100,00 ✓

- На руки 100 руб + УСН 8% + НДС 5%:
  Base = 100 / 0,92 = 108,70; НДС = 108,70 × 0,05 = 5,43; Платим **114,13**
  Проверка: 108,70 − 8,70 = 100,00 ✓

- На руки 100 руб + УСН 8% + НДС 22%:
  Base = 100 / 0,92 = 108,70; НДС = 108,70 × 0,22 = 23,91; Платим **132,61**

## Расчёт маржи и НДС к уплате

```
Маржа = Приход без НДС − Авт. без НДС (для физлиц и ИП без НДС — полная сумма)
НДС к уплате = НДС выходной − Авт. НДС входящий (к зачёту)
```

> Логика: у юрлиц/ИП с НДС реальная стоимость = сумма без НДС (они сами платят свой НДС). У физлиц и ИП без НДС — платим полную сумму.

**Пример — физлицо + ИП без НДС + юристы:**
- Приход с НДС: 1 351 476,00 → без НДС: 1 107 767,24; НДС вых.: 243 708,76
- ФТМ/Симонов (физлицо): 750 000 на руки → gross 862 068,97 (НДС 0)
- ИП Агафонов (без НДС): 75 000,00 (НДС 0)
- Юристы 7%: 11 166,67 × 1,07 = 11 948,33 (НДС 781,67)
- Авт. итого: 949 017,30 | НДС к зачёту: 781,67
- **Маржа: 159 531,61 руб. + НДС 22% к уплате: 242 927,09 руб.**

## Агентская / комиссионная сделка

SYNC LAB — агент, берёт % от суммы контракта. НДС контракта — НДС правообладателя, мы его **не платим**.

```
Комиссия без НДС = Сумма контракта (без НДС) × ставка комиссии
НДС комиссии = Комиссия без НДС × 0,22
Комиссия с НДС = Комиссия без НДС + НДС комиссии
НДС к уплате = НДС комиссии (только!)
Маржа = Комиссия без НДС
```
